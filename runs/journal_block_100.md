## §100. Разбор официального набора на формат и качество и материалы для итогового отчёта

### 100.1 Что это за измерение
Числа официального набора из 1319 задач для исходной модели, `w8` и `w50` были получены
раньше и нигде для отбора веток не использовались (§76.7 запрещает обратное). Здесь по ним
сделан только разбор: какая часть прироста объясняется оформлением ответа, а какая —
арифметикой. Скрипт `scripts/test_format_split.py`, файл `runs/analysis/test_format_split.txt`.
Новых прогонов не запускалось, файлы результатов читались как есть.

### 100.2 Разбор
Целиком на 1319 задачах:
  исходная модель — верно 680 (51,55 %), строк `FINAL` 1141 (86,50 %), обрывов 115;
  `w8` — верно 724 (54,89 %), строк `FINAL` 1239 (93,93 %), обрывов 76;
  `w50` — верно 709 (53,75 %), строк `FINAL` 1244 (94,31 %), обрывов 66.

Качество на задачах, где `FINAL` есть у обеих моделей (это и есть «чистая арифметика»):
  против исходной модели у `w8` пересечение 1092 задачи: 662 (60,6 %) -> 648 (59,3 %),
    переходы 104 лучше / 118 хуже, `p` = 0,3830;
  против исходной модели у `w50` пересечение 1096 задач: 663 (60,5 %) -> 641 (58,5 %),
    переходы 99/121, `p` = 0,1567;
  против `w8` у `w50` пересечение 1204 задачи: 715 (59,4 %) -> 700 (58,1 %),
    переходы 52/67, `p` = 0,1992.
Одновременно: задач, где `w8` оформил ответ, а исходная модель нет — 147, из них верных 76;
обратно — 49 задач, из них верных 18. У `w50` против исходной модели — 148 против 45,
верных 68 против 17.

### 100.3 Вывод по природе эффекта
Весь прирост на официальном наборе (+44 задачи у `w8`, +29 у `w50` против исходной модели)
объясняется оформлением и недопущением обрыва: на подмножестве задач, где обе модели дошли
до строки ответа, варианты не лучше исходной модели, а слегка хуже (−14 и −22 задачи,
оба различия внутри шума, `p` больше 0,15). На отборочных наборах картина иная по величине, но не по смыслу:
`w8` против исходной модели на пересечении 300 задач даёт +7 (65,7 % -> 68,0 %, `p` = 0,4350),
`w50` против исходной модели на пересечении 302 задач +4 (65,9 % -> 67,2 %, `p` = 0,6835), а между собой неразличимы
(215 против 214, `p` = 1,0). То есть ни один из проверенных способов правки весов не дал
устойчивого улучшения именно арифметики; устойчиво улучшается только дисциплина вывода.
Это и есть главный отрицательный результат серии, и он получён на трёх независимых
наборах: `dev` и `search` (350 задач), официальный (1319) и — впереди — удержанный (400).

заготовлена и не собиралась; измеренные прогоны считаются по каталогам с результатами
(82), уникальные наборы веса — по хешам манифестов (81).
