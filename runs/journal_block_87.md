## §87. Разложение эффекта на формат и качество, перепроверка ссылок и замер ресурсов

87.1. Разложение по объединённым `dev` и `search` (350 задач), считать будем так: задача
попадает в «чистое качество», если строка `FINAL` есть у обеих сторон сравниваемой пары.
Задача, где `FINAL` есть только у изменённой стороны, — это прирост исключительно формата,
потому что без строки `FINAL` ответ не извлекается и задача не может быть засчитана.
Итог по парам:
- исходная → `w8`: всего верных 202 → 216; чистое качество на пересечении 300 задач:
  197 → 204 (исправлено 33, сломано 26, `p` 0,4350); прирост только из формата: 32 задачи
  с `FINAL` только у `w8`, из них верных 12. То есть 12 из 45 новых верных ответов — формат,
  7 — чистое качество (33 минус 26), `p` не значим.
- исходная → `w50`: всего верных 202 → 217; чистое качество 302 задач: 199 → 203
  (29 исправлено, 25 сломано, `p` 0,6835); формат: 38 задач только у `w50`, верных 14.
- `w8` → `w81`: всего верных 216 → 212; чистое качество 317 задач: 213 → 206
  (7 исправлено, 14 сломано, `p` 0,1892); формат: 9 задач, верных 6.
Вывод по состоянию на этот ход: ни один измеренный вариант не показал улучшения качества
на множестве задач с `FINAL` у обеих сторон. Весь устойчивый прирост к контрольной точке
объясняется тем, что модель чаще доходит до строки `FINAL` и реже обрывается. Доля верных
среди задач с `FINAL`: исходная 65,2 %, `w81` 65,0 %, `w79` 64,1 %, `w50` 63,8 %, `w78` 62,8 % —
то есть прирост формата сопровождается небольшим падением качества на тех же задачах.
Это правило для итогового отчёта, а не результат отложенной проверки.
