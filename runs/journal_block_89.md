### §89.5 План «чёрного окна» — только план, ничего не остановлено и не запущено
Связь диалога: эта сессия отвечает через сервер на `http://127.0.0.1:8080/v1`. Значит выгрузка модели прерывает диалог: пока модель выгружена, отвечать нечем. Сервер сам закрывает движок (`STOP` и `QUIT`, затем `terminate`, затем `kill`) и сохраняет командную строку для повторного запуска, поэтому выгрузка — штатный путь, а не убийство процесса. Маршруты `unload` и `load` принимают только `application/json` и не принимают чужой `Origin` (415 и 403); `Origin: http://127.0.0.1:8080` принимается. `wait=1` на выгрузке означает «подождать текущий ход диалога до 300 секунд». `health` состояние только показывает, движок поднимают `load` и любой запрос генерации; если движок уже умер, выгрузка всё равно освобождает карту.

Порядок (файл-обёртка `scripts/w82_blackout.sh` — новый файл, создано 19.11.2026, синтаксис проверен, не выполнялся):
1. снимок: `PID` сервера 2330910 и движка 2330943, обе командные строки, конфиг, порт, память и видеокарта — в `runs/logs/strata_snapshot_w82.txt`;
2. выгрузка, пока диалог ещё жив:
```
curl -s -X POST -H 'Content-Type: application/json' -d '{}' 'http://127.0.0.1:8080/unload?wait=1'
```
3. проверка, что процесс движка исчез и память освободилась: `free -m`, `nvidia-smi --query-compute-apps=pid,gpu_uuid,used_memory`; запасной путь — `SIGTERM` процессу движка, сервер остаётся живым;
4. прогон одним фоном по `scripts/run_w82_disk.sh` (сборка в рабочем томе, только dev и search, один процесс);
5. восстановление на любом выходе — `trap` по `EXIT` поднимает сервер по записанной командной строке и загружает модель по `load`, при неудаче — крошечный запрос, который сам запускает движок;
6. после восстановления — новый замер порогов и блок §90 с вердиктом по полосе П82.1.

Ограничения: во время «чёрного окна» диалог невозможен, любой запрос к модели загрузил бы её на ту же видеокарту, поэтому писать в чат в это время нельзя; план требует решения пользователя до первой команды. `runs/discarded` не трогается, ничего не удаляется, пороги не понижаются.
